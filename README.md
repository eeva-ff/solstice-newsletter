# Solstice Product Updates

The weekly "What's new in Solstice" newsletter, published with GitHub Pages.

- Live site: https://eeva-ff.github.io/solstice-newsletter/
- Each issue is one Markdown file in `_posts/`, named `YYYY-MM-DD-whats-new.md`.
- The home page shows the newest issue; `/archive/` lists every issue.

To publish an issue, add the file to `_posts/`, commit and push to `main`. GitHub Pages rebuilds the site in about a minute.
