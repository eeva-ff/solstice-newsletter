## ✨ New

### Chat edit: change the creative and the PRC in one request

One request can now change both the creative and the PRC. You review them together, with one before/after and a single accept or revert.

When the agent has a question for you, it stays in the chat, and you answer it in the message box.

### MP4s are real asset versions

Videos now live on the asset page like any other version. Upload an MP4 as a new version, watch it play right in the canvas, and export it as an MP4 download or a view-only link to share.

Uploading is staff only for now, and review links for video aren’t available yet.

### Rename a brand yourself

Spotted a typo in a brand’s name? Anyone who can open the brand profile can now rename it from the Details section, no need to ask us.

## ⛑️ Fixed

- Manual edits on banners no longer break the layout, spacing or animation, or drop copy from other scenes when you save. ([SOL-3935](https://linear.app/solsticehealth/issue/SOL-3935))
- Agency banner ZIPs with one ZIP per size now upload properly, and the sizes are picked up. If a ZIP can’t be read, it’s kept as a normal upload with its proof and source attached, so your work doesn’t disappear behind an error. ([SOL-3836](https://linear.app/solsticehealth/issue/SOL-3836))
- Copy you paste into an intake request is used as written, instead of being treated as a reference file and rewritten. ([SOL-3956](https://linear.app/solsticehealth/issue/SOL-3956))
- Links to a folder inside a project now open that folder (thanks Ciaran and Vanessa!). ([SOL-3958](https://linear.app/solsticehealth/issue/SOL-3958))
- Renamed an asset? Quick search now finds it by its new name. ([SOL-3955](https://linear.app/solsticehealth/issue/SOL-3955))
- When an asset is handed to a new owner, they now get a notification, so nobody is left wondering whose it is. ([SOL-3912](https://linear.app/solsticehealth/issue/SOL-3912))
- Publishing now always uses the version shown in the picker, so you can’t accidentally publish the wrong one. ([SOL-3823](https://linear.app/solsticehealth/issue/SOL-3823))
- The agent can look at images again while it generates. This had quietly stopped working in production. ([SOL-3968](https://linear.app/solsticehealth/issue/SOL-3968))
- The briefing assistant stays on the brief: it politely turns down off-topic requests, and can’t be talked into a different role. Asking for shorter replies or another language still works. ([SOL-3872](https://linear.app/solsticehealth/issue/SOL-3872))
