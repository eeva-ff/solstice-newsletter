## ✨ New

### A new agent behind the chat editor

Chat edits now run on a new agent that works through your whole conversation in one go, deciding what to read, change and preview before it answers.

- **Comments, on the right version.** When a reviewer circles something, the agent opens the version the comment was made on, so it knows whether that thing still exists, has moved, or was already changed.
- **Point it at another asset.** Name another asset of the same brand, or paste its link, and the agent reads it as a reference. You can ask for a specific version too.
- **No more re-uploading.** It can read the files an asset was generated from, like the source paper or design image.
- **Says no less often.** Citations and reference lists can be edited along with the copy (thanks Paige!). Only library ISI text stays locked.
- **Sees what you see.** The PRC it checks uses the same styling as your viewer and the PDF export.

### Readiness check

Catch what MLR would catch before it gets there. Go to **Actions › Audit › Readiness check** and run it on any asset. It opens over the editor, with the asset right next to the results.

**What it checks:**

- **ISI:** does the ISI match the brand’s ISI library, and is it showing in every size?
- **Claims:** is every claim approved in the claims library, worded as approved, and carrying its caveats and reference marks?
- **Checklist:** the brand’s regulatory checklist, like the job code being there and in the right format, and copy that’s not too long.
- **Copy:** typos, doubled words and punctuation slips.

You get a summary with what needs fixing and what passed for each check, then a list of proposed fixes.

**Apply all fixes in one click.** Every fix is ticked to start with. Press **Apply fixes** and Solstice does the lot: the ISI is swapped for the library version, and everything else goes to the chat editor as one request, so you get one clean new version with every fix in it. Want different wording? Edit the proposed fix first, or untick anything you’d rather handle yourself.

Found something that’s fine as it is? Dismiss it with a reason, and the reason stays with the check. Then hit **Run again** on the new version to confirm it’s ready.

## ⛑️ Fixed

- Banners on the canvas stay sharp after you zoom or pan. No more clicking into edit mode to clear the blur (thanks Vanessa!). ([SOL-4062](https://linear.app/solsticehealth/issue/SOL-4062))
- Banner copy that had become uneditable can be typed into again, so you can change line breaks and wording (thanks Vanessa!). ([SOL-3960](https://linear.app/solsticehealth/issue/SOL-3960))
- Pressing Enter in a copy block adds a line break that survives saving, and the new line keeps the color and alignment of the first. ([SOL-4030](https://linear.app/solsticehealth/issue/SOL-4030))
- Selecting the same element in more than one banner size keeps a separate pin for each size, so chat changes only the sizes you picked, and removing one pin no longer drops the others. ([SOL-3961](https://linear.app/solsticehealth/issue/SOL-3961))
- PRC cover fields show the template’s color in the viewer and the PDF export, so desktop matches mobile. ([SOL-4032](https://linear.app/solsticehealth/issue/SOL-4032))
- Banners that wouldn’t open for editing because their saved code was cut short open again, and the next save repairs them. ([SOL-4085](https://linear.app/solsticehealth/issue/SOL-4085))
- Retrying a generation no longer creates a duplicate asset. ([SOL-4084](https://linear.app/solsticehealth/issue/SOL-4084))

## 🔜 Coming soon

### Campaigns, launching tomorrow!

Campaigns switch on tomorrow. Plan, brief and generate a whole campaign in one place:

- **Submit campaign** opens a confirmation that ticks the assets ready to generate and keeps the rest as drafts. Not ready yet? **Fill out required information** tells you what each asset is missing and where to add it.
- The campaign page has **Brief** and **Assets** tabs, with a progress card so you can see where every asset is. Assets waiting to start show as Queued.
- **Add asset → Create new**: pick how many emails, banners and social posts you want. They land at the end of the table as drafts, ready for their briefs.
- **Add asset → Add existing**: search and filter the brand’s assets and add several at once. If an asset already belongs to another campaign, it joins as a copy, so edits in one campaign leave the other alone.
- In the campaign chat, pick an element on a banner and ask for a change in only the sizes you picked.
- The chat on an asset page and in the campaign workspace takes attachments, shows every saved version with **View changes** and **Revert**, and has Quick, Standard and Thorough modes.
- Delete campaigns in bulk from the campaigns list. Their assets stay where they are.
- Clearer errors: one bar counts what needs attention, each field that needs a fix says what to do, and a failed asset gets a **Try again**.

### Also in testing

- **One-click “fix with chat” on comments:** send a reviewer’s comment straight to the chat, without losing anything you’d already typed.
- **Brand check:** a Brand row in the Readiness check that compares an asset’s colors and fonts with the brand setup and fixes near shades in one step.
- **Edit images in chat:** create, change, extend and animate images, and attach GIFs.
- **One “Submit new request” menu on Home:** new assets (now including video, print and slides), new campaigns, and edits to existing assets, including marking up an approved PDF.
- **Doximity MedUpdate articles:** generate the full article from a source paper, shown as its own page in the proof.
